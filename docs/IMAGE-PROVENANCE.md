# Image provenance

Bike and component images are category illustrations generated with the built-in Image Generation tool. They do not depict exact named models in the dataset. The README previews are captured from the working Power BI report.

## Parts illustration prompt

Use case: product-mockup. Asset type: header illustration for a Power BI bicycle components profitability report. Premium photorealistic studio catalog still life of unbranded bicycle parts: a graphite frame, spoked wheel, silver gear cassette, crankset and pedals, neatly arranged with clear separation. Wide landscape composition, all parts fully visible, mechanically plausible shapes, graphite and silver with restrained teal accents, seamless light warm gray background, soft studio lighting and subtle shadows. No complete bicycle, people, lettering, numbers, logos or watermark. Category illustration rather than an exact catalog product.

Saved source asset: assets/bike-parts.png in the working project; embedded in Bike Company.pbix. The road, mountain and touring prompts are retained in the reading guide.

The graphite comparison artwork was generated as a design background with the data areas left blank. Revenue, profit, margin, filters and the comparison chart are native Power BI visuals over that artwork. The Touring-3000 baseline loss is a fixed text callout.
